# Document extraction for the Company Profile pipeline.
#
# Before these, extraction handled a PDF's text layer, .txt and .csv, and
# returned an empty string for DOCX/XLSX/PPTX — so a pitch deck and a financial
# model contributed nothing to a profile, invisibly. MarkItDown covers the
# office formats. Scanned pages and text baked into deck images are read by
# sending the FILE to a document-capable model (see
# fundos/profile/pipeline/document_ai.py), which replaced the local Tesseract /
# EasyOCR engines — so there is no OCR binary to install any more.
#
# All four are optional at runtime: a missing package degrades that one file to
# "could not be read", with the reason recorded on the document row, and never
# fails a generation run.
# The EXTRAS ARE NOT OPTIONAL, despite the note above. Bare `markitdown`
# installs the converter classes but not the libraries they read with, so an
# .xlsx financial model raises MissingDependencyException, recovers 0
# characters, and category B (Financials) scores blank on every company —
# with nothing on the scorecard saying the model was never read. That is the
# exact failure this block was written to prevent, reintroduced one layer
# down. Pin the extras so the converters have what they need.
markitdown[docx,pptx,xlsx,xls,pdf]>=0.0.1a2   # native text/tables
